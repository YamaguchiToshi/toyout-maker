# ToyOut 音声づくり

声に、おもちゃを動かす合図（18.5〜19.5kHz の音）を重ねて、WAV ファイルを作る Web ページです。

https://yamaguchitoshi.github.io/toyout-maker/

できたファイルを iPad の AAC アプリ（DropTap など）のシンボルに貼り付けて再生すると、受信機が合図を聞き取り、声が流れているあいだ、選んだ CH のおもちゃを動かします。受信機（M5StickS3 と 4 チャンネルのリレー）は、VOCA の Toy Out 端子の代わりになります。

## 使い方

1. その場で録音するか、声のファイル（ボイスメモの m4a、wav など）を選ぶ。録音は 30 秒で自動的に止まる。「声を聞く」で確かめて、気に入らなければ「録り直す」。
2. 動かす CH（1〜4）を選ぶ。
3. 「試しに再生」で確かめ、「WAV を保存」で「"ファイル"に保存」を選んで保存する。ファイル App でそのファイルをコピーして、DropTap のシンボルに貼り付ける。

音声の処理はすべてブラウザの中で行い、ファイルはどこにも送りません。
